# Guides by task

Choose the operation your application needs. Each guide describes its authority, required host capabilities, and failure boundaries. For the first account connection, start with [Getting started](/getting-started/).

| Goal | Guide |
| --- | --- |
| Create, reopen, or assess recovery | [Account lifecycle](/guides/account-lifecycle) |
| Decide when a passkey or grant may act | [Authentication and consent](/guides/authorization) |
| Show holdings, deposit, or withdraw | [Assets and transfers](/guides/assets) |
| Add or remove devices and issue grants | [Devices and permissions](/guides/devices-grants) |
| Survive reloads, crashes, and unknown sends | [Persistence and background work](/guides/durability) |
| Supply browser, Node, wallet, or framework wiring | [Host integration](/guides/hosts) |

The SDK packages expose reusable flows and ports. The [reference demo](/demo/) chooses a UI, memory lease, wallet connection, and services for one local application; those choices are not automatic library behavior.

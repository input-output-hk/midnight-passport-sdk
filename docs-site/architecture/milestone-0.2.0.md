# What remains for 0.2.0?

**Snapshot: 16 November 2026.** The [0.2.0 milestone](https://github.com/input-output-hk/midnight-passport-sdk/milestone/2) has 15 open issues and one closed issue ([#244](https://github.com/input-output-hk/midnight-passport-sdk/issues/244)). An open issue may already have a tested subset; its remaining acceptance is still open. The #334 source stack began from merged [`passport-acc-prototype` at `95244f3`](https://github.com/input-output-hk/midnight-passport-sdk/tree/95244f322741e345698e524294c9b3de0509e086); later signed source commits are identified below. The published package release remains [`0.1.0-rc9`](https://github.com/input-output-hk/midnight-passport-sdk/releases/tag/sdk-v0.1.0-rc9). Source and localnet results do not silently become release, provider, or public-network qualifications.

The milestone groups candidate work; assigning an issue to it does not mean every Passport v1.0 promise must ship in one SDK release. [Architecture conformance](/architecture/conformance) separates source capability, test evidence, and the broader Passport target.

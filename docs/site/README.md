# GitHub Pages source

`docs/site` is the Jekyll source for the SDK's Pages site. `docs-pages.yml` builds and deploys it from the `passport-acc-prototype` branch. The repository owner must select **GitHub Actions** as the Pages publishing source before its first deployment.

Keep the API pages tied to exported source types. The site describes the prototype until packages are actually published; update package names and install examples in the same change that makes the packages public.
